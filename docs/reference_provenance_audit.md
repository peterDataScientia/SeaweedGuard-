# Reference provenance audit

42,628 FTIR metadata rows; 26 named organizations. 418 entries attributed to Rachel Kozloski were excluded. Two prior published libraries selected: Primpke et al. 2018 (123, doi:10.1007/s00216-018-1156-x); FLOPP, De Frond et al. 2021 (336, doi:10.1021/acs.analchem.1c02549). Total 459 unique sample_name IDs, 28 material classes. Remaining 41,751 entries not selected pending further source review. The complete audited CSV is stored in the project Drive folder, `06_OpenSpecy/reference_review_audited.csv`. The R workflow verifies row order and stable sample IDs before selecting. Source-level separation is not proof of spectral independence; exact/near spectral overlap and chemistry-label harmonisation remain pending. This is a restricted-library OpenSpecy benchmark, not full-library performance. R execution after these changes remains unverified.
