# Official OpenSpecy comparison protocol

Use the official derivative library and package matcher. Record package version, library metadata and provenance. Verify intensity units and derivative recipe against the installed library version. Exclude test-study sources and uncertain reference provenance before matching; check residual exact and near overlap separately. Preserve top-five native matches and review chemistry-level labels without changing the original truth. Compare paired outcomes on the 232 exposed spectra; these were already inspected during development and are not fresh independent validation. Report coverage and accepted error separately. No official benchmark results have been produced yet. Colab notebook intentionally stops for units and provenance review. R execution and API compatibility have not been tested in this environment.
