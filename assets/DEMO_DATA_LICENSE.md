# Demo data attribution

Lenz, Robin; Fischer, Franziska; Arnold, Melinda; Fernández-González, Verónica; Moscoso Pérez, Carmen María; Andrade-Garda, José Manuel; Muniategui-Lorenzo, Soledad; Fischer, Dieter (2023). **MicroPlastiX SpecDB**. https://doi.org/10.22000/1820.

Source data and adapted demo spectra: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Four deliberately selected measured ATR-FTIR examples, linearly interpolated to the E18 grid and rounded to five decimal places. Original filenames retained. The recorded results are original E18 frozen-engine outputs, not recalculated by replay. The reference bundle is not included. These examples demonstrate specific behavior, not an unbiased validation sample.
